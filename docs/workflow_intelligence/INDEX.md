# Workflow Intelligence

Workflow Intelligence captures recurring discoveries about how coaches actually
work under real training conditions. These documents describe operational
patterns that create product opportunities.

Workflow Intelligence is distinct from:

- **Coaching Intelligence**, which explains how coaches make decisions.
- **Product Decisions**, which define how AIP should behave.
- **Feature Specifications**, which define what should be built.

The purpose of this library is to preserve evidence about real coaching
workflows before those observations are translated into product decisions or
feature requirements.
